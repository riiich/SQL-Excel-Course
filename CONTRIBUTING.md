# Contributions are restricted

This is a proprietary project. Unsolicited modifications and contributions are
not authorized or accepted.

You may contribute only after the owner, `riiich`, gives you explicit written
permission. That permission must identify the work you may perform and whether
you may submit it to the official repository.

If permission is granted:

1. Work only within the written scope.
2. Use only the branch or delivery method authorized by the owner.
3. Reference the written permission in the pull request.
4. Do not push directly to the default branch.
5. Do not merge, publish, deploy, or redistribute the change.
6. Wait for the owner's GitHub code review and explicit approval of the final
   commit set. New commits invalidate the prior approval and require review
   again.

Opening an issue, fork, or pull request does not itself grant permission. The
owner may close or reject any unauthorized submission.
